Outdoor cold-plunge community (Puget Sound / Lake Washington) found via a
"Seattle sauna cold plunge" search. `/calendar` is a Wix Thunderbolt SPA —
the plain-fetched HTML is entirely the Wix renderer bootstrap with no
server-rendered event content. The site itself says "follow us on
Instagram or join our mailing list" to learn about future events, i.e.
there's no calendar page at all, just an Instagram-only announcement
model.

**Verdict**: Not viable — no server-rendered event data, organizer
explicitly directs people to Instagram/mailing list instead of a public
calendar.
