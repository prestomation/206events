Fine art gallery with two locations (Pioneer Square + SoDo), 1915 1st
Ave S. Site is Wix-hosted with per-month "First Thursday Art Walk, Open
Late" registration pages — no Squarespace/Eventbrite/ICS feed, and Wix
has no equivalent built-in ripper type in this repo. The only recurring
public event is the monthly First Thursday Art Walk, which is already
covered citywide by `sources/recurring/pioneer-square-artwalk.yaml`
(neighborhood-wide, not gallery-specific). Not worth a dedicated
scraper for a single gallery's participation in an already-covered
neighborhood event.
