Distillery with two locations: the original Seattle waterfront distillery
(tours only — Friday/Saturday tasting flights and behind-the-scenes tours,
no recurring public events program) and a Kenmore Barrel House location that
runs the actual events programming (dueling pianos, drag queen bingo, live
pro wrestling, seasonal cocktail classes).

Investigated 2026-09-08:
- `copperworksdistilling.com/category/events/` and the bare root both 404/400
  when fetched directly (root also appears to bot-block)
- The events-heavy programming found via search (dueling pianos, drag bingo,
  wrestling) is explicitly tied to the **Kenmore** barrel house
  (`copperworksdistilling.com/kenmore-events`), which is entirely outside
  Seattle city limits
- The Seattle waterfront location's own page only advertises tours, not a
  dated public events calendar

**Verdict**: Not viable as a Seattle source — the only structured
events program found is at the out-of-city Kenmore location, and the
Seattle location has no public events calendar to scrape.
