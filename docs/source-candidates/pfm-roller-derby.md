Seattle-area recreational roller derby league. Their calendar page embeds
a public Google Calendar (`pfmrollerderby@gmail.com`) and the public ICS
export works (`https://calendar.google.com/calendar/ical/pfmrollerderby%40gmail.com/public/basic.ics`
returns a valid VCALENDAR, 1734 events total).

Investigated 2026-07-26: the near-term upcoming entries are almost
entirely internal team logistics — "PFM Practice," "PFM League Meeting,"
"PFM New Skater!," bootcamp session names — not public spectator events.
No upcoming public bouts appear in the feed. Not a fit for a public event
calendar as-is; worth re-checking if they start listing public bouts on
the same feed.
