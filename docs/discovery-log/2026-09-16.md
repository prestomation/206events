Scanned the backlog for a candidate with real, currently-verifiable event
data rather than starting a fresh web search — most Eventbrite/Squarespace
candidates already on file (`clean-greens-farm-market`,
`innervisions-posters`, `ncnw-seattle-section`,

heavy reverse-engineering.

- ✅ Added: **Green Seattle Partnership** — citywide volunteer
  forest/park-restoration work parties run by Forterra's Green Seattle
  Partnership program. The org's own `greenseattle.org` marketing site is
  sgcaptcha-blocked (previously flagged in
  `docs/source-candidates/green-seattle-volunteer.md`), but its actual
  event platform, `seattle.greencitypartnerships.org`, is a plain,
  unprotected HTML calendar listing 30-40 upcoming work parties at any
  time across 30+ named Seattle parks/greenspaces. Implemented as a custom
  `IRipper` (`sources/green_seattle_partnership/`), `sourceRole: venue`
  (first-party organizer of its own program, same shape as `spl`), `geo:
  null` (per-event park-name locations, standard geocoding pipeline),
  tags `["Volunteer", "Outdoors"]`. Every event is parsed with `cost: {
  min: 0 }` directly (always free). 35 events, 0 parse errors verified via
  `ONLY_SOURCE=green-seattle-partnership`. See
  `docs/source-candidates/seattle-greencitypartnerships-org.md`.
