## Source discovery: implementing a candidate (Birds Connect Seattle)

Checked the two standing open PRs first (`#1453` seattle-food-trucks proxy
staging, `#760` 8-Bit Brass Band) — both unchanged, no action needed.
Confirmed `origin/main` is current, no rebase needed. Ran
`skills/source-discovery/scripts/dead-sources.py` against the production
`build-errors.json`: the 22 zero-event calendars and 15 external failures
are all already-tracked patterns (food-truck stops belong to the staged
`#1453`; the 14 `Browserbase fetch failed: HTTP 402` entries are billing
exhaustion, handled by `skills/proxy-escalation`; the remaining zero-event
calendars — SAM sub-venues, Downtown Seattle Association, Urban Family
Brewing, `external-seattle-made`, etc. — are pre-existing, previously
investigated gaps, not new) — nothing new to flag `dead`.

Ran fresh searches across birding/nature organizations, aquariums,
genealogy/history societies, public-speaking clubs, new-bar openings, and
immigrant/refugee community orgs. Most leads resolved to sources already
`added` (Seattle Aquarium via Eventbrite, Seward Park Audubon Center via
Mobilize.us — a separate National Audubon Society nature center, not the
same org as Birds Connect Seattle despite sharing a logo image).

- ✅ Added: **Birds Connect Seattle** (formerly the Seattle Audubon
  Society) — re-investigated after a 2026-06-18 `notviable` finding (no
  feed found in the static HTML). The `/calendar/` page actually embeds a
  **Tockify** calendar widget, which exposes a standard public ICS export
  at `https://tockify.com/api/feeds/ics/birds.connect.sea` — confirmed live
  with 101 VEVENTs (~49 upcoming from today), most carrying real structured
  `LOCATION` addresses. The bulk of locations are Seattle-proper (HQ at 616
  Olive Wy, Union Bay Natural Area, Seward Park Nature Center, Carkeek
  Park, Ballard Locks), with a handful of regional field trips (Redmond,
  Edmonds, Kirkland, Issaquah, Olympia) acceptable under the "few events
  outside city limits" rule. Implemented as
  `sources/external/birds-connect-seattle.yaml` — best-case ICS
  integration, no custom code. `sourceRole: venue`, `geo: null` (per-event
  geocoding), `weatherSetting: "mixed"` (genuine mix of indoor HQ talks and
  outdoor field trips — per `lib/config/tags.ts`, `Outdoors` is reserved
  for unambiguously open-air sources, so it's omitted here in favor of the
  mixed overlay). Tags `Education`, `Community`. 101 raw events / 57 in the
  near-term index, 0 parse errors, 4 non-fatal geocode errors (a few
  imprecise park-parking-lot addresses, left for the geo-resolver queue),
  verified via `ONLY_SOURCE=birds-connect-seattle npm run
  generate-calendars`; full `npm run test` (3919 tests, 223 files) green.
  See `docs/source-candidates/birds-connect-seattle.md`.
- 🔄 Status fix: **Casa Latina** (`casa-latina.org/events/`) — no longer
  403s from this environment, but re-investigation shows the events page is
  a static WordPress page-builder layout listing sporadic one-off
  fundraisers, with only **one** confirmed upcoming item and no custom
  "event" post type exposed via REST (`wp-json/wp/v2/types` returns `post`
  only). Too thin and no structured feed; flipped `blocked` → `notviable`.
- ❌ Not Viable: **Seattle Genealogical Society** (`seagensoc.org`) — static
  listings table with only ~2 annual seminars + occasional virtual
  meetings; no ICS/API and too thin for a standalone source. See
  `docs/source-candidates/seattle-genealogical-society.md`.
- ❌ Not Viable: **Seattle Toastmasters clubs** — a dozen-plus independent
  clubs citywide, each running a generic, indistinguishable recurring

  `docs/source-candidates/seattle-toastmasters-clubs.md`.
