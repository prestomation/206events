Two genuinely new leads investigated to a disposition:

  page is a client-rendered Next.js SPA, but it calls a real JSON API
  (`/api/events`) with clean structured data (title, description, ISO
  start/end dates, cost, registration URL, venue id) — would be a trivial
  `JSONRipper` implementation on data quality alone. However, the venue
  geography is Puget Sound-wide rather than Seattle-focused: of the
  events with future dates at check time, roughly half were outside
  Seattle city limits (Gallery North in Edmonds, Parklane Gallery in
  Kirkland, a Vashon Island studio tour, a Renton studio tour, Maple
  Valley Days, BIMA on Bainbridge Island). Fails the Seattle-focused gate
  despite the branding. `notviable`. See
  `docs/source-candidates/seattleartists-com.md`.

  `sgcaptcha` JS bot-challenge signature already recorded for
