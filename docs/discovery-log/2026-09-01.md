## Source discovery: existing candidate implementation (Club Sake)

- ✅ Added: Club Sake (Seattle SAKE Paddling Club) — dragon boat, OC6
  outrigger canoe, and SUP sports club with frequent weekly training
  sessions at Leschi South Sailboat Moorage and Lakewood Marina. The
  `club-sake.md` candidate had flagged the gated `revolutioniseSPORT`

  filtering manually-flagged cancellations. Added a `KNOWN_VENUE_COORDS`
  entry for "Leschi South Sailboat Moorage" in `lib/geocoder.ts` (OSM
  way 52135058) since the bare venue name doesn't resolve via Nominatim
  on its own. Verified live via `ONLY_SOURCE=club-sake npm run
  generate-calendars`: 77 events, 0 parse errors — PR pending.

## Source discovery: existing candidate implementation (Zulu's Games)

  Gathering drafts/FNM/prereleases, Flesh and Blood tournaments, Star Wars

  Implemented as `sources/external/zulus-games.yaml` (ICS, no custom ripper
  code). Registered `Bothell` as a new neighborhood tag in `city.config.ts`
  (precedent: Kenmore/Renton/Shoreline/Tukwila/Lake Forest Park already
  carry their own suburb tags). Added a `KNOWN_VENUE_COORDS` entry for
  "Zulu's Guildhall" (same venue, room nickname used by some feed entries)
  in `lib/geocoder.ts`. Verified live via `ONLY_SOURCE=zulus-games npm run
  generate-calendars`: 0 config/parse/geocode errors — PR pending.
