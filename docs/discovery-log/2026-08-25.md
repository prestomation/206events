## Source discovery: aggregator gap analysis (2026-08-25)

Ran a gap analysis against a large Seattle-metro event sample from a third-party
event aggregator to find sources we don't yet cover. Pulled 1,500 events across
3 viewports (Seattle metro, Eastside, South Seattle), extracted the source domain
from each event's `url`, and diffed against our existing inventory (519 known
domains from `sources/` + `sources/external/`).

**Result: 154 new candidate files** written to `docs/source-candidates/` for
uncovered source domains.

### Top uncovered sources (by event count in sample)
- **seattleymca.org** (69) — YMCA classes/events
- **kcls.bibliocommons.com** (53) — King County Library events
- **trivianearme.net** (32) — trivia nights
- **do206.com** (27) — Seattle events aggregator
- **teamsideline.com** (25) — rec sports
- **app.pugetsoundbasketball.com** (20) — rec basketball
- **momence.com** (20) — class/workshop booking platform
- **olympicathleticclub.com** (18) — OAC events
- **mountaineers.org** (18) — outdoors/fitness
- **tukwilawa.gov** (16) — city events
- **kidsquestmuseum.org** (14) — family museum
- Plus ~140 more lower-volume sources (city gov sites, dance orgs, bookstores,
  music venues, rec sports, etc.)

### Platform/aggregator candidates (kept as `candidate`, pointed at specific page)
- luma.com, nextdoor.com, imgoodevents.com, do206.com, apm.activecommunities.com,
  anc.apm.activecommunities.com, fareharbor.com (Savor Seattle Tours),
  promotix.com, seatgeek.com, songkick.com, bandsintown.com

### Content sites (marked `notviable` — editorial, not structured event sources)
- secretseattle.co, greaterseattleonthecheap.com, parentmap.com,
  seattle.kidsoutandabout.com, seattlemet.com, kingcountylocalblog.com,
  425magazine.com

### Genuine gaps (root domain not covered)
- kingcounty.gov (King County Parks events), nps.gov (NPS free entrance days),
  apm.activecommunities.com (Seattle Parks & Rec activities)

These are all candidates for the source-discovery skill to pick up and implement.
