## Source discovery: existing candidate implementation (Watershed Pub & Kitchen)

- ✅ Added: The Watershed Pub & Kitchen — Northgate/Lake City neighborhood
  pub (10104 3rd Ave NE) hosting live music, trivia, a silent book club,
  cider tastings, and periodic food/beer events. The existing
  `watershedpub-com.md` candidate was a bare aggregator-gap stub; a fresh
  investigation found the `/events` page is fully server-rendered HTML
  (React Router SSR, "bevwerk" platform) — no proxy or JS execution
  needed — but has no ICS/JSON feed, so implemented as a custom
  `HTMLRipper` (`sources/watershed_pub/ripper.ts`, `sourceRole: venue`,
  tags `["Nightlife", "Northgate"]`). The site's free-text
  `.blurb-date` field mixes perpetually-recurring blurbs (no date),
  closure/hours notices (date with no time), and real timed events
  (single date+time, same-day range, or short multi-day range); the
  parser uses the presence of "@" plus a 14-day span cap to keep only
  genuine one-off occurrences. 7 events, 0 errors confirmed via
  `ONLY_SOURCE=watershed-pub npm run generate-calendars` against the
  live site.
