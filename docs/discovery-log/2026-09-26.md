## Source discovery: King County CivicPlus cities + music/community/outdoors rotation

Second run today. No open source-discovery PR to sweep (checked — only
unrelated open PRs exist). Rotated to verticals not covered by the
earlier run: music venues, community centers, bookstores, Eventbrite
organizer search, running/outdoors, and King County suburb city
calendars (Sammamish, Issaquah, Vashon, Enumclaw, Snoqualmie, North
Bend). Most hits from the first five searches were either aggregator/
directory sites (Songkick, SeatGeek, EverOut, Ticketmaster discover
pages — not single organizations) or already-`added` candidates (Sync
Seattle, Seattle Running Club, Populus Seattle) — this pool is heavily
mined.

The King County suburb-city rotation found real gaps: `sources/issaquah/`
already covers Issaquah's CivicPlus/CivicEngage iCalendar module
(`/common/modules/iCalendar/iCalendar.aspx?catID=<id>&feed=calendar`), so
checked whether other King County cities on the same platform were
missed. Confirmed North Bend and Enumclaw run the identical platform with
live, un-implemented "Community Events" categories; Snoqualmie has one
too but mixed with generic holiday-closure noise; Sammamish uses a
different platform (CivicWeb) with no discoverable events feed.

- 💡 Candidate: **Vashon Events** (vashonevents.org) — Squarespace,
  aggregator covering Vashon Island (King County) — confirmed 38
  upcoming events via `?format=json`. 🔥 High confidence, built-in type.
- 💡 Candidate: **City of North Bend** — CivicPlus iCalendar, `catID=21`
  ("Community Events") — 11 live events (What's Brewing North Bend,
  Trail Fest, Blues Walk, Arbor Day/Oaktoberfest, etc.), no
  committee-meeting noise. 🟡 Needs a small custom ripper (same pattern
  as `sources/issaquah/`, whose `normalizeLocation` is directly
  reusable for the `<p>Venue</p> - address` LOCATION format).
- 💡 Candidate: **City of Enumclaw** — CivicPlus iCalendar, `catID=23` —
  6 live events (Frosty Friday Evenings, Pumpkin Succulent Workshops,
  craft/vendor show, harvest event). Same custom-ripper pattern as
  North Bend/Issaquah.
- 🔍 Investigating: **City of Snoqualmie** — same CivicPlus platform,
  `catID=14` has ~6 real events mixed with ~8 generic holiday-closure
  entries that need title-based filtering beyond the whole-category
  skip North Bend/Enumclaw/Issaquah use — needs a bit more design before
  it's a straightforward candidate.
- ❌ Not viable: **City of Sammamish** — different platform (CivicWeb),
  no ICS/RSS/JSON events feed found on `sammamishwa.gov/news/events/`;
  the CivicWeb portal it links to is for meeting agendas, not events.
