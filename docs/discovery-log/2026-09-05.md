searches this cycle; triaged several previously-flagged Community/venue
candidates before implementing the highest-confidence viable one.

  (three dedicated per-page parsers: Trick or Treat 34th Ave, Monthly
  Meetings, Music In The Playfield) — 2 events confirmed live in a local
  `ONLY_SOURCE` build (the third page's dated Tuesdays had already passed
  for the season). See `docs/source-candidates/madrona-neighborhood-association.md`.

  recurring events on `/recurring-events` (Art Attack, Farmers Market) are
  already covered by `sources/recurring/georgetown-artwalk.yaml` and
  `sources/recurring/georgetown-farmers-market.yaml`; the seasonal annual
  events are covered elsewhere or carry no scrapable date on that page.
- 🔍 Investigating / re-confirmed unchanged: Poquitos Seattle, Phinney
  Books, Dog Yard Bar (still 0 upcoming events on their Squarespace
  collections), Clean Greens Farm & Market, NCNW Seattle Section,
  Innervisions Posters & Framing (still 0 upcoming Eventbrite events),
  Grey Drizzle Fibers (still 0 Seattle-proper events, Renton/Bellevue
  only), Kandelia (Modern Events Calendar RSS feed still empty), Seattle
  Yoga News (Tribe Events REST API still `total: 0`, ICS export still an

## Source discovery: outdoors/sports (climbing, running, disc golf), food pop-ups, nightlife/markets sweep (2026-09-05, second cycle)

Ran `dead-sources.py` against production first — 9 zero-event calendars
(`eastlake-community-council-all-events`, `fremont-brewing-all-events`,
`marymoor-movies-all-events`, `roam-bar-roam-bar`, `tag-redmond`,
`external-el-centro-de-la-raza`, `external-on-the-hiyu`,
`external-seattledances`, `external-shunpike`) and 2 external failures
(`discover-magnolia`, `seattle-indies`, both HTTP 403). None crossed the
30-day-dead threshold on this single snapshot alone (no historical streak
data available in this environment beyond the current build) — leaving
as-is rather than flagging `dead` without stronger evidence; worth a
follow-up with `event-history.json` if they persist.

Searched outdoor recreation, beer/brewery, food festivals, holiday
markets, Eventbrite organizer discovery, new bars, night markets, drag
venues, running clubs, new art galleries, pop-up dinners, silent disco,
warehouse/gallery spaces, car shows, climbing gyms, disc golf leagues,
and community-center calendars. The overwhelming majority of hits are
already-covered sources (Volunteer Park Trust, Reuben's Brews, Fremont
Brewing, Washington Beer Blog, Columbia City Night Market, Seattle Night
Market, Capitol Hill Running Club, West Seattle Runner, Seattle Running
Club, Flying Lion Brewing, Fleet Feet Ballard, Gray Sky Gallery, Unicorn,
Julia's on Broadway/Le Faux, National Nordic Museum, Cannonball Arts,
Seafair — whose ICS feed already covers Greenwood Car Show, Ballard
Seafoodfest, and other Seafair-family street fairs, Edgeworks, Bouldering
Project, Vertical World, The Mountaineers) or already-tracked candidates
re-surfaced by the same searches (Seattle Women in Tech, Fast Fashion
Brewing, Greenlake Brewing, Assembly Art Fair, Silent Disco NW/Secret
Sunset Seattle, Silent Dance Alki, Seattle Pop-Up Menu, MixMix Socials) —
no change to any of their statuses this cycle.

  (`docs/source-candidates/momentum-climbing-sodo.md`, `notviable` since
  2026-08-07); this cycle's search resurfaced it via third-party mentions
