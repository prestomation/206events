## Source discovery: candidate implementation cycle (Community/neighborhood associations)

Picked up from the existing `candidate` queue rather than running fresh
searches this cycle; triaged several previously-flagged Community/venue
candidates before implementing the highest-confidence viable one.

- ✅ Added: Madrona Neighborhood Association — custom HTML `IRipper`
  (three dedicated per-page parsers: Trick or Treat 34th Ave, Monthly
  Meetings, Music In The Playfield) — 2 events confirmed live in a local
  `ONLY_SOURCE` build (the third page's dated Tuesdays had already passed
  for the season). See `docs/source-candidates/madrona-neighborhood-association.md`.
- 🔄 Status fix: Georgetown Coalition Recurring Events → `notviable`. Both
  recurring events on `/recurring-events` (Art Attack, Farmers Market) are
  already covered by `sources/recurring/georgetown-artwalk.yaml` and
  `sources/recurring/georgetown-farmers-market.yaml`; the seasonal annual
  events are covered elsewhere or carry no scrapable date on that page.
- 🔍 Investigating / re-confirmed unchanged: Poquitos Seattle, Phinney
  Books, Dog Yard Bar (still 0 upcoming events on their Squarespace
  collections), Clean Greens Farm & Market, NCNW Seattle Section,
  Innervisions Posters & Framing (still 0 upcoming Eventbrite events),
  Grey Drizzle Fibers (still 0 Seattle-proper events, Renton/Bellevue
  only), Kandelia (Modern Events Calendar RSS feed still empty), Seattle
  Yoga News (Tribe Events REST API still `total: 0`, ICS export still an
  empty body), King County Parks Events (still county-wide, no
  Seattle-proper events), 48 North SARC (still only 1 of 9 clubs in the
  feed is Seattle-based, no per-event location to filter on), SODO BIA
  (previously found behind a SiteGround JS-challenge — not re-tested this
  cycle).
- ❌ Not viable (new finding): King County Library System Events
  (BiblioCommons SPA, `/v2/events.json` returns the HTML shell not JSON —
  would need browser automation to find the real XHR endpoint), Evergreen
  Speedway (Monroe, WA — outside Seattle city limits, borderline even
  before the TicketGoat scraping question), Emerald City Softball (games
  occur at North SeaTac Park — outside Seattle — and the 2026 schedule is
  currently a PDF, not yet posted), GeekGirlCon (single annual convention,
  no ICS/API/ticketing platform found; would need a hand-maintained
  fixed-date entry re-verified every year).
